# Ditto Maker

Phaser 4 + TypeScript 로 만드는 2D 웹 게임입니다.

## 플레이

브라우저에서 바로 실행됩니다. 설치할 것은 없습니다.

**https://ssam1221.github.io/DittoMaker/**

> 처음 열면 화면을 한 번 클릭하거나 아무 키나 눌러야 음악이 나옵니다.
> 브라우저가 사용자 조작 전에는 소리 재생을 막기 때문이며, 버그가 아닙니다.

### 메인 화면

| 입력 | 동작 |
| --- | --- |
| `↑` `↓` (또는 `W` `S`) | 메뉴 이동 (선택할 수 없는 항목은 건너뜁니다) |
| `Enter` / `Space` | 선택 |
| 마우스 | 올리면 선택, 클릭하면 실행 |
| `M` | 음소거 켜기 / 끄기 |

### 게임 중

| 입력 | 동작 |
| --- | --- |
| `←` `→` | 이동 |
| `↑` | 점프 |
| `Esc` | 메인 화면으로 |
| `M` | 음소거 켜기 / 끄기 |
